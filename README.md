# React SPA Boilerplate (Vite + TS + Tailwind + gh-pages)

## Quick start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy to GitHub Pages

1. Update `homepage` in `package.json` if your GitHub username/repo differs.
2. Update `repoName` in `vite.config.ts` if repo name differs.
3. Run:

```bash
npm run deploy
```

This publishes `dist/` to the `gh-pages` branch.
